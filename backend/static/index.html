使用提示 (Hint)
  • 本项目已开源：github
  • 本地版隐私：无登录/注册/云同步功能；服务仅监听 127.0.0.1。FGO / Stream Response 只在浏览器本地解析，原始抓包不会上传到后端。
  • 计算时不考虑前排加成。
  • 冠位戴冠战：打开“冠位戴冠战模式”即可。求解器按普通自备5张 + 自家Grand额外报酬礼装1张（0 Cost）+ 助战Grand 2张来计算，共8个羁绊加成位；Cost直接填写游戏中的实际上限，不再手工 +12。
  • 特殊礼装：若带黑杯等非羁绊礼装，则减去对应Cost和礼装数量。
  • 羁绊10：按“当前未继续解锁”处理，默认从刷羁绊候选中排除。
  • 羁绊15：已达当前上限时自身收益为0，但仍提供「夢火の導き」全队+25%；若已开放更高上限（如日服15→16），则自身继续获得羁绊，同时仍提供+25%。多骑可叠加，求解器自动比较最优人数。
  • 长期 Box 均衡：司机降低培养权重、老板提高培养权重，并结合导入的精确羁绊进度优先照顾“平时没人带”的低进度从者；“固定出场”是独立硬约束，不等于高培养优先级。

FGO / Stream Response：可直接导入抓到的完整 toplogin Response（支持原始 JSON、URL 编码或 Base64 文本）。全部解析只在当前浏览器本地完成，仅提取持有从者、羁绊等级/累计羁绊和当前实际持有的满破羁绊礼装；不会把原始响应、userId、usk、sign 等账号字段保存到 Box 或发送给后端。导入前会显示抓包时间，旧快照会额外警告。

Chaldea CSV：在 Chaldea 的羁绊详情页导出 CSV 后直接导入，可一次同步持有从者、当前羁绊等级、累计羁绊、Next 与各等级累计阈值；按 svtId 匹配，不依赖名字。导入会把 CSV 作为当前英灵 Box 的权威快照，但保留你已经标好的“司机/老板、优先级、固定出场”。

Box 使用完整从者主数据：即使某位从者当前不命中任何条件型 +20% 羁绊礼装，也仍可登记。羁绊10默认排除；羁绊15会作为「夢火の導き」+25% provider 参与求解：已达当前上限者自身0收益，15→16等仍可继续培养者自身正常获得羁绊。礼装库存只限制自己的礼装，不限制好友助战礼装。
